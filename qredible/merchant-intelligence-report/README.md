# Merchant Intelligence Report: where it lives

A proposal page for sign-off, published 2026-11-19.

- `index.html` is the proposal: where the report sits in Qredible, who can open it, how it is paid for, how someone can try it from the website, and five points to approve or change. The sign-off controls only build a block of text for the reviewer to copy and send. Nothing is submitted anywhere.
- `screens/` holds six sample screens of the report as plain HTML with inline styles and no scripts.
- `img/` holds the pictures of those screens used on the proposal page.

Every merchant, person and number on the sample screens is made up. Nothing here is built yet, and nothing is wired to data.
