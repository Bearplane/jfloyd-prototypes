QP-3909

QP-3909 — Variant COA Required: AI Bulk Determination. The product classification sets the COA requirement that the parent and all variants inherit by default — so the obvious majority (weight/size variants of the same formulation) costs zero AI. This bulk action in Product Compliance → Products is the on-demand override for ambiguous families — strain, color, and composition variants where "different" actually means a different cannabinoid profile. The AI evaluates each variant using product name, classification, variant attributes, description, product images, and live site where available. Each AI determination is human-overridable before applying.
