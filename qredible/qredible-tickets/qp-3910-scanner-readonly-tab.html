⚠️ Open Layout Question for Joseph

PRIMARY build above (Section B) shows the collapsed single resolved list — recommended: simpler, shows exactly what will run.

SECONDARY alternative (Section C) keeps the four-tab scope drill-down, which preserves context about where each check comes from at each level.

Tradeoff:

  • Single resolved list — cleaner, directly answers "what will run?" but loses per-scope granularity visible to power users.
  • Four tabs (read-only) — shows scope context but adds visual complexity and may confuse users who expect the tabs to be editable.
→ Both are built here for review. Please confirm which layout to ship.
