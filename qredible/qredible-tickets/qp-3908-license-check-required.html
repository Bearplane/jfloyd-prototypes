QP-3908  ·  Context

QP-3908 — Industry-Level "License Check Required" Flag. Adds a configurable toggle per industry type. Industries without it (Parking, Digital Assets, On-Line Dating, etc.) show "N/A — Not Applicable" in We Monitor license status instead of the misleading "License Not Found". No code deploy required to enable checks for a new vertical — just set the flag.
