QP-3898 — Partner Code Tracking

Adds a partner_code field to Q-Audit Finances and the We Monitor Invites flow. When an invited company converts to a paid subscription, the partner code propagates to the finances record — enabling revenue attribution back to the referring processor or ISO (FlexPay, Westtown, etc.). Sections A and C show the current state; Sections B and D show the proposed changes.
