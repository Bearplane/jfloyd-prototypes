QP-3962 — Bulk upload: Processor Company Reference as primary dedup key

When a processor bulk-uploads companies, the existing deduplication logic matches incoming rows against existing records using legal company name, city, and state — a combination that can produce false matches for merchants that share similar names or operate across locations. This change promotes the Processor Company Reference field to the primary dedup key: when a row carries a reference value, the system looks for an existing company with that reference first (requiring city + state to also agree as a guard); rows without a reference continue to fall through to the existing name + city + state logic unchanged.

Section 4 — Dedup logic
Deduplication behavior — QP-3962 updated flow

Section 5 — Implementation scope
