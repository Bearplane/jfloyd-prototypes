✦ Principle: the system is too detailed — Ask-Q should make it feel smaller, not add a fifth surface

3 · Ask a question (no AI)

5 · What's real vs. new
Click the Ask-Q pill in the top bar (or ⌘K, which already exists). Before you type anything, Q shows the six things people actually do for the company you're looking at — with live counts pulled from the same statistics the KPI tiles use. Every tile is a deep link into a screen the app already has. Nothing here is a new capability; it's a shorter path to an existing one.

Type a word and Q searches products, COAs and screens at once — scoped to what this user can already see (it reuses each listing's own query). Product rows carry the two or three verbs that matter right on the row: open it, open its COA family chain, assign a COA. No submenus. Matching actions ("upload", "match") show up as you type them.

Ask a plain question and Q answers with one number and the next step. No AI is needed for this: the small set of questions people actually ask ("how many are missing a COA?", "what's violative?", "anything expired?") maps directly onto the statistics the page already loads, so the answer is always the same number the KPI tile shows. AI phrasing can be added later behind topBar_assist_01 without changing this screen.
